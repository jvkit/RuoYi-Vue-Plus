# 13-字典怎么用：从创建到前后端显示

## 1. 字典到底是干嘛的？

字典就是「下拉框选项列表」。

比如发票类型，数据库里存的是 `normal`、`special`、`electronic`，但用户看到的是：

```text
normal        → 增值税普通发票
special       → 增值税专用发票
electronic    → 电子普通发票
```

这个「值 → 中文标签」的映射，就是字典。

---

## 2. 字典在哪里管理？

```
系统管理 → 字典管理
```

里面有两层：

- **字典类型**：一个分类，比如 `invoice_type`（发票类型）。
- **字典数据**：具体的选项，比如 `normal=增值税普通发票`。

---

## 3. 新建一个字典（以「报销类型」为例）

### 第 1 步：新增字典类型

```
系统管理 → 字典管理 → 字典类型 → 新增
```

填写：

| 字段 | 值 |
|---|---|
| 字典名称 | 报销类型 |
| 字典类型 | `reimbursement_type` |
| 状态 | 正常 |

### 第 2 步：新增字典数据

在「报销类型」这一行，点「字典数据」按钮，进入后新增：

| 字典标签 | 字典键值 | 排序 | 是否默认 |
|---|---|---|---|
| 差旅费 | `travel` | 1 | 是 |
| 办公用品 | `office` | 2 | 否 |
| 招待费 | `entertainment` | 3 | 否 |

现在你就有一个字典 `reimbursement_type`，包含三个选项。

---

## 4. 前端怎么使用字典？

### 4.1 在表格里显示字典标签

假设后端返回的数据是：

```json
{
  "reimbursementType": "travel"
}
```

前端表格列这样写：

```vue
<el-table-column label="报销类型" align="center" prop="reimbursementType">
  <template #default="scope">
    <dict-tag :options="reimbursement_type" :value="scope.row.reimbursementType" />
  </template>
</el-table-column>
```

然后在 `<script setup>` 里拉取字典：

```ts
const { proxy } = getCurrentInstance() as ComponentInternalInstance;
const { reimbursement_type } = toRefs<any>(proxy?.useDict('reimbursement_type'));
```

`useDict('reimbursement_type')` 会自动从后端拉取这个字典的所有选项。

### 4.2 在表单下拉框里使用字典

```vue
<el-form-item label="报销类型" prop="reimbursementType">
  <el-select v-model="form.reimbursementType" placeholder="请选择报销类型">
    <el-option
      v-for="dict in reimbursement_type"
      :key="dict.value"
      :label="dict.label"
      :value="dict.value"
    />
  </el-select>
</el-form-item>
```

---

## 5. 后端怎么使用字典？

后端通常**只存字典值**，不存中文标签。

```java
private String reimbursementType;  // 存 travel / office / entertainment
```

查询列表时直接返回这个值，中文翻译交给前端的 `<dict-tag>`。

如果需要在后端做判断，比如「只能查询差旅费」，直接比字符串值：

```java
lqw.eq(Reimbursement::getReimbursementType, "travel");
```

---

## 6. 代码生成器怎么自动用字典？

代码生成器在导入表之后，可以设置每个字段的显示方式：

```
系统工具 → 代码生成 → 导入表 → 编辑
```

在字段配置里：

- **显示类型**：选择 `下拉框`。
- **字典类型**：选择 `reimbursement_type`。

生成的代码会自动：

- 前端表单用 `<el-select>` + 字典选项。
- 前端表格用 `<dict-tag>` 显示中文。
- 后端字段存字典值。

---

## 7. 一个完整例子

假设你要做一个「报销申请」模块：

1. 数据库表 `reimbursement_request` 里有个字段 `type`。
2. 在字典管理里建 `reimbursement_type`。
3. 代码生成器导入表，把 `type` 字段的显示类型设为「下拉框」，字典选 `reimbursement_type`。
4. 生成前后端代码。
5. 运行后，页面上自动出现下拉框，表格自动显示中文。

---

## 8. 总结

| 使用场景 | 怎么做 |
|---|---|
| 新增字典 | 系统管理 → 字典管理 → 新增类型和数据 |
| 前端下拉框 | `useDict('字典类型')` + `el-option` 遍历 |
| 前端表格显示 | `<dict-tag :options="字典" :value="值" />` |
| 后端存储 | 字段存字典值（如 `travel`） |
| 代码生成器 | 字段显示类型选「下拉框」，绑定字典类型 |

字典的目的就是：**后端存简单的代码，前端显示友好的中文，改文案不用改代码**。
