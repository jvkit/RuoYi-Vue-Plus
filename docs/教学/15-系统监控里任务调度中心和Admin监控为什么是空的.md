# 15-系统监控里任务调度中心和 Admin 监控为什么是空的

## 1. 先说结论

这两个模块点开没东西，**不是因为系统坏了，而是因为对应的后端服务没有启动**。

RuoYi-Vue-Plus 是一个多模块项目，很多功能拆成了独立模块：

| 前端菜单 | 对应后端模块 | 当前是否启动 |
|---|---|---|
| 任务调度中心 | `ruoyi-job` | ❌ 未启动 |
| Admin 监控 | `ruoyi-monitor` + Spring Boot Admin Server | ❌ 未启动 |

所以你看到的是空页面。

---

## 2. 任务调度中心是干嘛的？

### 2.1 一句话解释

**任务调度中心 = 管理定时任务的地方。**

比如：

- 每天晚上 2 点自动备份数据库。
- 每小时同步一次员工考勤数据。
- 每月 1 号自动生成报表。

这些「到了某个时间就自动执行」的任务，就是定时任务。

### 2.2 RuoYi 里的实现

RuoYi-Vue-Plus 的定时任务模块叫 `ruoyi-job`。

它有两种执行方式：

| 方式 | 说明 |
|---|---|
| 本地执行 | 任务代码直接跑在 `ruoyi-job` 模块里 |
| 远程调用 | 通过 HTTP 调用其他模块的接口执行任务 |

### 2.3 为什么现在是空的？

当前环境里只启动了 `ruoyi-admin` 模块，`ruoyi-job` 没有启动，所以：

- 没有任务列表。
- 没有执行日志。
- 页面是空的。

### 2.4 要启动吗？

如果你们暂时不需要定时任务，**不用启动**。

如果需要，启动命令类似：

```bash
cd /home/jvkit/workspace/oa/RuoYi-Vue-Plus/ruoyi-job
nohup java -jar target/ruoyi-job.jar --server.port=9100 > /tmp/ruoyi-job.log 2>&1 &
```

启动后，「任务调度中心」就会有数据。

---

## 3. Admin 监控是干嘛的？

### 3.1 一句话解释

**Admin 监控 = Spring Boot Admin，用来监控后端服务运行状态。**

可以看到：

- 有哪些服务实例在运行。
- 每个服务的 CPU、内存、线程、GC 情况。
- 服务的健康检查状态。
- 实时的日志级别调整。

### 3.2 为什么现在是空的？

Admin 监控需要两个东西：

1. **Spring Boot Admin Server**：独立服务，负责收集各个客户端的信息。
2. **Spring Boot Admin Client**：每个业务模块（如 `ruoyi-admin`、`ruoyi-job`）注册到 Server。

当前环境里这两个都没启动，所以页面是空的。

### 3.3 要启动吗？

如果你们只是学习/开发阶段，**不用启动**。

如果是生产环境，可以考虑启动监控，方便排查问题。

---

## 4. 现在哪些监控是有数据的？

虽然任务调度和 Admin 监控是空的，但系统监控里其他几项通常是有数据的：

| 菜单 | 是否有数据 | 说明 |
|---|---|---|
| 在线用户 | ✅ 有 | 当前登录的用户 |
| 操作日志 | ✅ 有 | 用户的操作记录 |
| 登录日志 | ✅ 有 | 用户登录记录 |
| 缓存监控 | ⚠️ 可能有 | Redis 监控，需要权限 |
| 任务调度中心 | ❌ 空 | `ruoyi-job` 未启动 |
| Admin 监控 | ❌ 空 | `ruoyi-monitor` 未启动 |

---

## 5. 这些非致命告警你之前也见过

后端日志里常见这两条：

```text
UnknownHostException: net — Spring Boot Admin 客户端注册失败
SnailJob gRPC 连不上 127.0.0.1:17888 — 调度中心未启动
```

就是因为 `ruoyi-monitor` 和 `ruoyi-snailjob-server` 没启动。不影响登录和常规接口。

---

## 6. 总结

| 问题 | 答案 |
|---|---|
| 任务调度中心是干嘛的 | 管理定时任务 |
| Admin 监控是干嘛的 | 监控后端服务健康状态 |
| 为什么点开没东西 | 对应后端模块没启动 |
| 需要启动吗 | 学习阶段不需要，生产环境按需启动 |
| 影响正常功能吗 | 不影响 |

---

## 7. 如果要启动完整版

启动顺序：

1. MySQL、Redis（已启动）
2. `ruoyi-admin`（已启动）
3. `ruoyi-job`（定时任务）
4. `ruoyi-snailjob-server`（SnailJob 调度中心）
5. `ruoyi-monitor`（Spring Boot Admin Server）

全部启动后，系统监控里的空页面就会有数据了。
