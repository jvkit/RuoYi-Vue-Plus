# 08-租户、租户套餐、父子联动是什么意思

## 1. 要不要为公司 A 新建租户？

### 1.1 两种选择

| 选择 | 做法 | 数据是否隔离 | 适用场景 |
|---|---|---|---|
| **用当前租户** | 在当前租户 `000000` 里创建一个「员工」角色和用户 | 不隔离 | 公司 A 就是你自己的公司，只是区分管理员和员工 |
| **新建租户** | 创建一个公司 A 的租户，再在里面建角色和用户 | 隔离 | 公司 A 是独立客户，数据要独立 |

### 1.2 简单判断标准

- 如果公司 A 就是你们自己公司，只是想让普通员工登录看看 → **用当前租户**。
- 如果公司 A 是另一个客户/分公司，你希望它有自己的数据、自己的管理员 → **新建租户**。

### 1.3 本文场景建议

既然你提到「为公司 A 做一个员工端」，默认按**独立客户**理解，建议**新建租户**。这样可以完整体验 RuoYi 的多租户能力。

但如果你只是想快速验证「员工视角」，用当前租户也完全没问题，步骤更少。

## 2. 什么是租户套餐？

### 2.1 一句话解释

**租户套餐 = 一组菜单权限的打包。**

你可以把它理解为 SaaS 产品的「套餐」：

- 基础版套餐：只能用请假、报销。
- 专业版套餐：能用请假、报销、采购、发票。
- 旗舰版套餐：所有功能都能用。

### 2.2 在 RuoYi 里的作用

创建租户时，必须选一个套餐。这个套餐决定了该租户下的用户能看到哪些菜单。

套餐里存的是 `menuIds`，也就是一组 `sys_menu` 表里的菜单 ID。

### 2.3 为什么需要套餐？

如果没有套餐，每次创建租户都要手动勾选一堆菜单，容易漏、容易错。

有了套餐，你可以先定义好：

```text
员工基础套餐 = [请假申请, 我的待办, 我发起的, 发票上传]
管理员全量套餐 = [所有菜单]
```

创建租户时直接选套餐，省时省力。

## 3. 父子联动是什么意思？

### 3.1 出现的位置

创建/编辑租户套餐时，会让你勾选菜单，旁边有个选项叫**父子联动**。

### 3.2 直接说含义

它控制的是**菜单树里勾选父菜单时，子菜单要不要一起被勾选**。

| 父子联动 | 效果 |
|---|---|
| **开启（1）** | 勾选「发票管理」目录，会自动勾选下面的「发票信息」菜单和「新增/删除」按钮 |
| **关闭（0）** | 勾选「发票管理」目录，只勾它自己，子菜单不会自动被勾选 |

### 3.3 用图表示

菜单树大概长这样：

```
□ 发票管理          ← 目录（父）
  □ 发票信息        ← 菜单（子）
    □ 发票信息新增  ← 按钮（孙）
    □ 发票信息删除
```

**开启父子联动时**：

- 你勾选「发票管理」，下面的「发票信息」、「新增」、「删除」自动全部勾选。
- 你取消勾选「发票管理」，下面全部取消。

**关闭父子联动时**：

- 你勾选「发票管理」，只有它自己被勾选。
- 你想让员工能用，还得一个个手动勾选「发票信息」、「新增」、「删除」。

### 3.4 推荐设置

**一般建议开启父子联动**，否则套餐配置起来非常麻烦，容易漏子菜单。

## 4. 创建公司 A 租户的完整步骤（零代码）

### 第 1 步：进入租户套餐管理

```
系统管理 → 租户套餐
```

### 第 2 步：新增一个「公司 A 员工套餐」

填写：

- 套餐名称：`公司 A 员工套餐`
- 关联菜单：勾选员工需要的菜单
  - 工作流 → 请假申请
  - 工作流 → 我的待办
  - 工作流 → 我发起的
  - 采购管理 → 采购申请
  - 发票管理 → 发票信息
- 父子联动：**开启**
- 状态：正常

### 第 3 步：进入租户管理

```
系统管理 → 租户管理
```

### 第 4 步：新增租户「公司 A」

填写：

- 企业名称：`公司 A`
- 联系人：`张三`
- 联系电话：`13800000000`
- 用户名：`admin_a`（这是公司 A 的管理员账号）
- 密码：`admin123`
- 租户套餐：选择刚才创建的「公司 A 员工套餐」
- 过期时间：可以选 1 年后
- 用户数量：`-1` 表示不限制

保存后，系统会自动：

1. 创建租户 `000001`（或下一个可用编号）。
2. 创建公司 A 的管理员账号 `admin_a`。
3. 根据套餐，给公司 A 初始化菜单权限。

### 第 5 步：用 admin_a 登录

退出当前 admin，用 `admin_a / admin123` 登录。

注意：登录时要选租户（如果前端支持租户选择），或者在域名/参数里指定租户。

默认登录页通常有租户下拉框或根据域名判断。

### 第 6 步：在公司 A 里创建普通员工

登录 `admin_a` 后：

```
系统管理 → 用户管理 → 新增
```

创建员工账号，分配角色。如果只想让员工用套餐里的功能，可以给一个默认员工角色。

---

## 5. 如果不用租户，只想在当前租户里测试员工视角

步骤更简单：

```
系统管理 → 角色管理 → 新增「员工」角色
系统管理 → 用户管理 → 新增测试员工，分配「员工」角色
```

然后退出 admin，用测试员工登录，左侧菜单就只剩员工权限了。

---

## 6. 一个常见坑

创建租户时如果提示「租户套餐不能为空」，但你又没建过套餐，是因为**必须先创建套餐，才能创建租户**。

RuoYi 默认没有内置通用套餐，所以需要你自己先点几下创建。

---

## 7. 总结

| 概念 | 一句话 |
|---|---|
| **租户** | 一个独立公司/组织，数据互相隔离 |
| **租户套餐** | 一组菜单权限的打包，创建租户时直接选 |
| **父子联动** | 勾选父菜单时，是否自动勾选所有子菜单 |
| **是否新建租户** | 公司 A 是独立客户就新建；只是内部员工测试就用当前租户 |
