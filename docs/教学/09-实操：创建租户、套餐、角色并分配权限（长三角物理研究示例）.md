# 09-实操：创建租户、套餐、角色并分配权限（长三角物理研究示例）

## 0. 先理清两个层级

RuoYi 的权限分两层：

1. **租户套餐**：决定这个租户**能看到哪些菜单**。
2. **角色权限**：决定这个租户里的某个用户**能操作哪些菜单和按钮**。

类比：

- 租户套餐 = 商场里的「楼层导览图」，告诉你这层有哪些店铺。
- 角色权限 = 你手里的「门禁卡」，决定你能进哪些店铺、能按哪些按钮。

所以步骤是：

```
创建套餐 → 创建租户 → 用租户管理员登录 → 创建角色 → 创建用户并分配角色
```

---

## 第 1 步：创建租户套餐

### 1.1 进入菜单

```
系统管理 → 租户套餐
```

### 1.2 点击「新增」

填写：

| 字段 | 填写内容 |
|---|---|
| 套餐名称 | `长三角物理研究-基础套餐` |
| 状态 | 正常 |
| 父子联动 | **关闭**（后面解释为什么） |

### 1.3 勾选菜单

由于只需要「发票管理」和「用户管理」，**父子联动建议关闭**，否则勾选父目录会把所有子菜单都带进来。

需要勾选的菜单：

```text
□ 系统管理              ← 目录，必须勾选，否则下面的用户管理出不来
  □ 用户管理            ← 菜单
    □ 用户查询          ← 按钮权限
    □ 用户新增
    □ 用户修改
    □ 用户删除
    □ 用户导出
    □ 用户导入
    □ 重置密码

□ 发票管理              ← 目录，必须勾选，否则下面的发票信息出不来
  □ 发票信息            ← 菜单
    □ 发票信息查询
    □ 发票信息新增
    □ 发票信息修改
    □ 发票信息删除
    □ 发票信息导出
```

> 注意：「角色管理」不用勾选，因为普通租户管理员一般不需要创建角色。如果需要，可以额外加上。

### 1.4 保存

保存后，这个套餐就创建好了。

| 字段 | 填写内容 |
|---|---|
| 企业名称 | `长三角物理研究` |
| 联系人 | `张三` |
| 联系电话 | `13800000000` |
| 统一社会信用代码 | 可空，或填一个测试值 |
| 用户名 | `admin_phys` |

保存后，系统会：

- 创建租户管理员账号 `admin_phys`。
- 根据套餐初始化该租户可用的菜单。

## 第 4 步：创建普通用户角色

### 4.1 进入菜单

```
系统管理 → 角色管理
```

### 4.2 点击「新增」

填写：

| 字段 | 填写内容 |
|---|---|
| 角色名称 | `普通员工` |
| 权限字符 | `common_employee`（自定义，用于标识这个角色） |
| 显示顺序 | `1` |
| 状态 | 正常 |

### 4.3 勾选菜单权限

在角色编辑页面的菜单树里，只勾选：

```text
□ 发票管理
  □ 发票信息
    □ 发票信息查询
    □ 发票信息新增
```

**不要勾选**：

```text
□ 发票信息修改
□ 发票信息删除
□ 发票信息导出
□ 系统管理
□ 用户管理
```

### 4.4 保存

保存后，这个角色的权限字符就是：`common_employee`。

## 7. 权限字段对照表

下面是本次用到的权限字符，方便你理解：

### 7.1 发票管理权限

| 权限字符 | 含义 | 普通员工是否需要 |
|---|---|---|
| `invoice:info:list` | 查看发票信息菜单和列表 | ✅ 需要 |
| `invoice:info:query` | 查看发票详情 | ✅ 需要 |
| `invoice:info:add` | 新增发票 | ✅ 需要 |
| `invoice:info:edit` | 修改发票 | ❌ 不需要 |
| `invoice:info:remove` | 删除发票 | ❌ 不需要 |
| `invoice:info:export` | 导出发票 | ❌ 不需要 |

### 7.2 用户管理权限

| 权限字符 | 含义 | 普通员工是否需要 |
|---|---|---|
| `system:user:list` | 查看用户管理菜单 | ❌ 不需要 |
| `system:user:query` | 查询用户 | ❌ 不需要 |
| `system:user:add` | 新增用户 | ❌ 不需要 |
| `system:user:edit` | 修改用户 | ❌ 不需要 |
| `system:user:remove` | 删除用户 | ❌ 不需要 |
| `system:user:resetPwd` | 重置密码 | ❌ 不需要 |

## 8. 常见问题和注意点

### 8.1 为什么父子联动要关闭？

如果开启父子联动，勾选「系统管理」目录时，会自动勾选下面的「用户管理」、「角色管理」、「菜单管理」、「字典管理」等所有子菜单。

但公司 A 只需要「用户管理」，其他都不需要，所以关闭父子联动，手动勾选需要的即可。

### 8.2 不勾选父目录，只勾选子菜单可以吗？

**不建议。**

如果「发票管理」目录没勾选，只勾选了「发票信息」，左侧菜单可能显示不出来，因为系统找不到它的父级。

正确做法是：父目录勾选，子菜单按需勾选。

### 8.3 套餐和角色有什么区别？

| | 套餐 | 角色 |
|---|---|---|
| 配置对象 | 租户 | 用户 |
| 作用 | 这个租户能有哪些菜单 | 这个用户能操作哪些菜单和按钮 |
| 类比 | 商场楼层导览 | 个人门禁卡 |

### 8.4 套餐里勾选了「用户管理」，但角色里没勾选，普通员工能看到吗？

**不能。**

套餐只是让「用户管理」这个菜单对租户可用，但具体谁能看到，还要看角色权限。

所以：

- 套餐给租户管理员用（admin_phys）。
- 角色给普通员工用（lisi）。

### 8.5 如果以后想让员工也能修改自己上传的发票怎么办？

进入「角色管理」，编辑「普通员工」角色，勾选 `invoice:info:edit`，保存即可。

不需要改代码。

## 9. 总结

为「长三角物理研究」搭建员工权限的流程：

```text
1. 创建套餐「长三角物理研究-基础套餐」
   └── 勾选：系统管理 → 用户管理（及按钮）
   └── 勾选：发票管理 → 发票信息（及按钮）

2. 创建租户「长三角物理研究」
   └── 管理员账号：admin_phys / admin123

3. 用 admin_phys 登录

4. 创建角色「普通员工」
   └── 只勾选：发票信息查询、发票信息新增

5. 创建用户「李四 / lisi」
   └── 分配角色：普通员工

6. 用 lisi 登录测试
   └── 只能看到「发票管理 → 发票信息」
   └── 只能新增，不能修改、删除、导出
```
