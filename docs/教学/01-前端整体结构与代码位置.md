## 四、router/ 路由目录

```
src/router/
└── index.ts                # 路由总配置
```

RuoYi 的路由是**动态加载**的：

1. 登录成功后，前端调用后端接口 `/system/menu/getRouters`
2. 后端返回菜单树（包含 component 路径）
3. 前端把菜单树转换成 Vue Router 路由对象
4. 动态添加到路由表里

所以**侧边栏不是写死在路由文件里的**，而是后端 `sys_menu` 表驱动的。

`src/router/index.ts` 里主要存放：
- 登录、注册、首页等固定路由
- 路由守卫（登录校验、权限校验）
- 动态添加后端菜单路由的逻辑

## 八、怎么根据页面找代码？（实战方法）

### 方法一：看 URL 路径

比如当前页面 URL 是：

```
http://127.0.0.1/system/user
```

那对应的页面组件大概率是：

```
src/views/system/user/index.vue
```

### 方法二：看浏览器开发者工具

1. 在页面上按 F12
2. 选中某个元素
3. 看 Vue 组件名（需要安装 Vue DevTools）

### 方法三：直接搜索菜单名称

比如想找"菜单管理"的代码：

```bash
cd /home/jvkit/workspace/oa/plus-ui
grep -r "菜单管理" src/views/system/menu/
```
