## 一、访问方式

### 1.1 电脑端

打开浏览器，访问：

```
http://172.16.16.110/oa/
```

推荐使用 **Chrome / Edge / Firefox** 浏览器。

### 1.2 手机端

手机与电脑连接同一局域网后，浏览器访问：

```
http://172.16.16.110/oa/
```

或在系统内点击底部「手机端专属」菜单，进入手机端验收页面。

## 三、角色说明

| 角色 | 权限说明 |
|---|---|
| 普通用户 | 可提交采购申请、采购验收、仓库领用申请；可查看采购、项目、仓库等菜单 |

| 部门上级 | 审批金额 **≥ 1000 元** 的采购申请 |

| admin | 系统管理员，可操作所有功能、代批所有流程 |

## 五、采购申请

### 5.1 进入页面

左侧菜单 → **采购管理** → **采购申请**

### 5.2 新建采购申请

1. 点击「新增」按钮
2. 填写采购申请表单：
   - **标题**：系统自动生成，格式为 `【自购/对公】+ 项目名 + MM月DD日 + 名称`
   - **项目归属**：点击选择项目，支持树形展开
   - **采购种类**：选择「科研」或「非科研」
   - **采购分类**：树形选择，如 `100 材料` → `101 金属材料`
   - **付款截图**：上传付款凭证图片
   - **其他字段**：按需填写
3. 添加采购明细：
   - 点击「添加明细」
   - 填写商品名称、规格、数量、单价
   - 系统会自动计算总价
   - 选择供应商（明细级）
4. 确认金额不超过项目可用资金
5. 点击「提交」启动审批流程

### 5.3 采购申请审批流程

```
提交申请 → 项目负责人审批 → 根据总金额自动分支：
  ├─ 金额 < 1000 元 → 团队上级（王建龙）审批 → 结束
  └─ 金额 ≥ 1000 元 → 部门上级（李迪）审批 → 结束
```

### 5.4 查看审批进度

在采购申请列表中，点击「详情」或「流程进度」查看当前审批节点。

## 六、采购验收

### 6.1 进入页面

左侧菜单 → **采购管理** → **采购验收**

### 6.2 发起验收

1. 点击「新增」按钮
2. 选择已通过审批的采购申请
3. 系统会自动带出采购申请的商品明细
4. 对每个商品：
   - 上传验收照片
   - 上传发票 PDF
   - 确认实际单价/金额
5. 点击「提交」启动验收审批流程

### 6.3 验收审批流程

```
提起验收 → 采购申请人确认 → 项目负责人审批 → 团队上级审批 → 结束
```

> 注意：验收人不一定等于采购申请人。验收由验收人发起，但第一步需要原采购申请人确认。

### 6.4 验收状态说明

| 状态 | 含义 |
|---|---|
| 未验收 | 该采购申请尚未发起验收 |
| 验收中 | 已发起验收，正在审批流程中 |
| 已完成验收 | 验收流程已结束，商品可入库 |

## 七、AI 发票识别匹配

### 7.1 功能说明

在采购验收页面，支持一次性上传多个发票 PDF，AI 会自动：

1. 识别每张发票的字段（发票代码、号码、销售方、购买方、金额、商品名等）
2. 判断是否为冲红发票
3. 根据商品名和金额，自动匹配到对应的验收明细
4. 自动回填发票金额、上传发票文件
5. 生成匹配报告：
   - 成功匹配的发票
   - 缺少对应商品的发票
   - 多页/无法识别的发票（仅识别第一页）

### 7.2 使用方法

1. 在采购验收页面，点击「AI 识别发票」按钮
2. 在弹窗中拖拽或选择多个发票 PDF
3. 点击「开始识别」
4. 等待 AI 处理完成
5. 查看匹配报告，确认自动填充结果
6. 如有未匹配的发票，可再次上传补充

### 7.3 注意事项

- 目前只识别发票 PDF 的 **第一页**
- 金额口径使用 **不含税金额**
- 商品名会尽量与订单明细匹配，若发票商品名过长可能匹配失败，建议人工核对
- 冲红发票会自动标记并提示

## 十二、常见问题

### Q1：提示「没有访问权限，请联系管理员授权」怎么办？

A：请联系管理员（admin）确认您的账号是否绑定了正确的角色。普通用户应绑定「普通用户」角色，审批人应绑定对应审批角色。

### Q2：提交采购申请时提示「项目资金不足」怎么办？

A：请确认所选项目的剩余预算是否足够。如需调整项目预算，请联系管理员。

### Q3：采购验收时找不到某个采购申请？

A：只有审批通过的采购申请才能发起验收。且每个采购申请只能发起一次验收（除非验收被驳回）。

### Q4：AI 识别发票后金额没有回填？

A：请检查发票商品名是否与订单明细商品名差异过大。AI 按商品名和金额匹配，若无法匹配会保留为空，需手动填写。

### Q5：流程审批被驳回后怎么办？

A：在对应列表页找到该单据，点击「详情」查看驳回原因，修改后重新提交。

### Q6：手机端验收页面打不开？

A：请确认手机与服务器在同一局域网（172.16.16.x），并访问 `http://172.16.16.110/oa/`。
