# 2026-09-02 验收权限修复 + AI识别留痕 + 仓库只读 + 手机端上传修复

> 本轮改动均为**本地**修改，未部署到服务器。对应后端提交 `0b911255e`（ruoyi-6x）、前端提交 `3663a70`（plus-ui-6x）。

## 一、本轮修复的 4 个问题

### 1. AI 识别结果留痕（此前关闭弹窗即丢失）

**问题**：验收单使用 AI 识别发票后，关闭识别窗口就再也看不到识别内容，多次识别的历史也无处可查。

**方案**：在 `pms_acceptance` 加 `ai_detail` 列（v10 幂等 SQL），AI 每次识别匹配的结果按轮次**追加**写入该字段，随验收单表单一起保存。前端提供「AI识别详情」入口，弹窗左侧为滚动历史列表（多次识别全部保留），右侧为当次识别详情。

另外修复了一个连带 bug：`ai-invoice-match` 接口新增 `requestId` 参数——验收草稿尚未落库时发起识别，台账记录此前会丢失关联（acceptance_id/request_id/project_id），现在补上。

### 2. 「补齐材料」按钮（多轮上传队列残留）

**问题**：第一次上传 abc（ab 无效、c 识别成功），再次上传 de 时队列变成 abcde 并重复识别 abc，浪费且混乱。

**方案**：前端识别弹窗在识别完成后，若存在未匹配上的商品，提示「补齐材料：当前还有 N 个商品缺少发票，本轮只需拖入缺口发票，已识别的不会重复处理」，按钮变为「开始识别（补齐材料）」，点击前清空队列中已处理文件，只处理本轮新拖入的。

### 3. 仓库库存：普通用户只读

**问题**：普通用户（fengzhongjun 等）打开仓库库存提示无权限，看不到库存就没法发起领用申请；而操作按钮又不该给普通用户。

**方案**：v9 幂等 SQL 调整菜单权限——`common_user` 补绑仓库库存 list/query（库存可见），移除其仓库操作按钮（add/edit/remove）；仅 `warehouse_admin` 角色保留操作权限。前端 `warehouse/index.vue` 用 `v-hasPermi` 控制按钮显隐。

### 4. 手机端验收：拍照上传偶发失败

**问题**：手机端（K90 Max 实测）首次点击拍照上传，拍照完成后照片偶尔不上传，有时重试又成功，疑似首次触发相机权限被挂起。

**方案**：手机端上传组件改为**点击重试**——上传失败时文件条目保留并显示「上传失败，点击图片重试」，点击该条目即重试上传。不做过度设计（不自动重试、不申请额外权限）。
