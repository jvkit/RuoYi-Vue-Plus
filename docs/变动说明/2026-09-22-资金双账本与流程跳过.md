## 变更摘要

1. **资金双账本**：项目账本（预算/已用/剩余，逻辑不变）+ 备用金账本（按人额度占用制，新增）。两本账互不影响——备用金侧任何操作都不改变项目已用金额。
2. **备用金额度账户**：新表 `pms_reserve_account`，一人一行，默认额度 10000（`sys_config` 可配），管理员可改。占用/可用/已回笼**不落库，实时聚合**采购申请得出。
3. **资金状态机**：采购申请新增 `fund_status`，三态单向不可回溯：`已采购未报销 → 已报销未汇款 → 已报销已汇款`；对公申请置 `不适用`。审批通过自动进第一态，后续推进由资金管理人员在页面勾选，全程留痕（操作人 + 时间）。
4. **资金流水带分账维度**：流水新增 `title_type`（自购/对公）、`applicant_id`、`applicant_name`（=谁的钱，取申请单 create_by）。
5. **资金管理页改造**：顶部两组卡片 + 四个 Tab（项目视图 / 备用金视图 / 资金状态管理 / 资金状态看板），流水明细加「采购方式」「申请人」筛选。
6. **新角色「采购经理」**（`procurement_manager`），资金管理与报销的可见+可操作角色；默认指派王建龙。普通用户维持不可见。
7. **流程暂跳过最高决策人**：采购申请流程网关 `>=1000` 出边改指 `end`，零代码、可一条 SQL 恢复；节点与角色绑定全部保留。
8. **顺带修掉三个历史坑**：`procurement:fund:edit`（sync 接口）无菜单定义、`procurement:reimbursement:edit/:remove` 无菜单定义、采购申请列表 `dict-tag` 读 undefined.options 报错。

## 关键业务口径（实现严格遵循，改代码前先看这段）

| # | 口径 | 实现位置 |
|---|---|---|
| K1 | 拨入/额度**不算**项目已用 | 备用金不写项目账本，`used` 只由采购申请审批通过累加 |
| K2/K3 | 自购、对公采购**都扣**项目预算 | `checkBudget()` / `calcUsedAmountByProject()` 未改动 |
| K4 | 对公**与备用金无关** | 聚合 SQL 只统计 `title_type='自购'`（含历史空值）；对公 `fund_status=not_applicable` |
| K5 | 回笼**只释放备用金占用**，项目已用不变 | `fund_status=reimbursed_paid` 后该笔退出 occupied 聚合；项目 used 无任何回退逻辑 |
| K6 | 备用金按**人**记额度 | `pms_reserve_account.person_id` 一人一行 |

备用金计算公式（全部实时聚合，无余额表）：

```
occupied(人)  = Σ 申请金额 WHERE create_by=人 AND title_type='自购' AND status='finish'
                              AND fund_status IN ('purchased_unreimbursed','reimbursed_unpaid')
recycled(人)  = Σ 申请金额 WHERE 同上 AND fund_status='reimbursed_paid'
available(人) = quota − occupied
```

## 本次踩坑记录（避免重复）

1. **`autoPass` 不能用来跳过别人的节点**。`CompleteAutoPassComponent` 只自动跳过「当前登录人仍是办理人」的后续任务，CEO 审完不会碰最高决策人（李迪）的节点。跳过别人只能改网关出边或写节点监听器。
2. **改 `flow_skip.next_node_code` 必须同步改 `next_node_type`**（end=2，普通审批节点=1），只改 code 引擎会按旧类型流转。
3. **恢复语句不能写成可执行 SQL 放在 `script/sql/` 下**——`apply-sql.sh` 会把目录里所有未记录脚本跑一遍，恢复脚本会立刻把跳过改回去。已用注释形态存放。
4. **`pkill -f 'ruoyi-admin.jar'` 会杀掉自己的 shell**（命令行里含同样字符串），要用 `pkill -f '[r]uoyi-admin\.jar'` 或走 `scripts/start-6x.sh`。
5. **新增 `dict-tag` 必须确认页面声明了对应 `useDict`**，否则 `DictTag` 内部 `props.options.some(...)` 抛 `Cannot read properties of undefined`，且只在浏览器控制台报，构建和 lint 都不报。
6. 备用金账户表**不要建 `person_id` 唯一索引**：本表走逻辑删除，唯一索引会导致「删了再建同一人」失败，唯一性交给 Service 先查后插。
