# 2026-09-02 发票台账展示优化 + 仓库库存图片回显

## 变更摘要

1. **角色调整**：将 `wangjianlong` 绑定 `superadmin` 角色，使其拥有完整管理员菜单与权限。
2. **发票台账展示优化**：
   - 移除不存在的 `ticket` 图标，改为 `ep:collection`。
   - 列表去掉“发票代码”列（与发票号码重复且无实际内容）。
   - 新增/调整列：商品名称、关联验收单、关联申请、项目归属。
   - 关联申请显示采购申请标题，项目归属显示项目名称，关联验收单显示验收单编码。
   - 开票日期统一格式化为 `yyyy-MM-dd`。
   - 搜索区增加“项目”下拉筛选。
   - 普通用户角色（common_user）不再可见发票台账菜单及按钮。
3. **仓库库存优化**：
   - 入库日期格式化为 `yyyy-MM-dd`。
   - 新增“验收图片”列，从验收明细 `photo_url` 回填，前端通过 OSS ID 解析为真实 URL 并支持点击预览。
4. **发票匹配落库**：AI 识别到的匹配商品名写入 `invoice_info.matched_items`，台账“商品名称”列直接展示。
