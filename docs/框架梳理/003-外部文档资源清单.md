## 七、如何使用这些文档

### 7.1 离线启动 docsify（plus-doc / warm-flow-doc）

```bash
# 进入对应目录
# plus-doc
cd docs/外部文档/plus-doc
npx docsify serve

# warm-flow-doc
cd docs/外部文档/warm-flow-doc
pnpm i
pnpm docs:dev
```

### 7.2 直接用 VSCode 阅读 Markdown

所有文档都是 Markdown，直接用 VSCode 打开即可搜索关键词。

### 7.3 搜索关键词建议

- 权限相关：`@SaCheckPermission`、`DataScope`、`data_scope`、`permission_flag`
- 工作流相关：`permission_flag`、`skip_condition`、`listener`、`variable`
- 用户相关：`LoginHelper`、`LoginUser`、`deptId`
