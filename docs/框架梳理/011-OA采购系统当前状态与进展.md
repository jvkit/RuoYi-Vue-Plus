## 二、已经实现的模块

### 2.1 项目管理

**已实现：**
- 多级项目树（长三角 → 本地隐私保护项目 → RAG/Agent）
- 项目编码自动生成
- 项目负责人绑定
- 项目预算字段
- 归属部门字段（存在，但权限未完全用起来）

**已知问题：**
- 子项目预算未强制校验不大于父项目（或校验逻辑有漏洞）
- 列表中项目编码仍显示，需要隐藏
- 归属部门在表单中展示不够明显

---

### 2.2 采购申请

**已实现：**
- 采购申请列表、新增、编辑、详情
- 申请编码自动生成
- 标题自动生成（由用户输入名称 + 项目名 + 日期拼接）
- 项目选择（树形）
- 采购类型（自购/对公）
- 采购种类（科研/非科研）放到申请表单
- 采购明细：物品名称、规格、数量、单价、总价、供应商
- 总金额自动计算
- 提交后启动工作流

**已实现的工作流：**

```
申请人提交 → 项目负责人 → 金额分支
                          ├── < 1000  → 团队上级（王建龙）
                          └── ≥ 1000  → 部门上级（李迪）
```

**已知问题：**
- 普通用户（非 admin）权限不足，无法提交申请或看到操作按钮
- 列表中申请编码仍显示，需要隐藏
- 标题应显示用户输入的名称，完整标题只用于导出
- 驳回后的申请单查看/重新提交有问题
- 当前审批人显示有时不准

---

### 2.3 采购验收

**已实现：**
- 验收单列表、新增、编辑
- 关联采购申请（避免重复验收，但实现有漏洞）
- 验收明细：实际数量、实际单价、发票金额、发票附件、验收图片
- 提交后启动工作流

**已实现的工作流：**

```
验收人提起 → 原采购申请人 → 项目负责人 → 团队上级 → 结束
```

**已知问题：**
- 重复验收控制不严格
- 验收日期时间格式显示异常（`2026-08-04T00:00:00.000+08:00`）
- 审批视角图片加载失败、附件 404
- 驳回后的审批单打不开
- 移动端验收页面点击无反应（`Toast.loading is not a function`）
- 验收完成后自动入库逻辑需确认是否稳定

---

### 2.4 仓库/库存

**已实现：**
- 仓库物品列表（来源：验收通过的采购明细）
- 库存数量显示
- 领用申请入口
- 领用申请列表

**已实现的工作流：**

```
申请人提交领用 → 仓库管理员（裴天姿） → 结束
```

**已知问题：**
- 领用审批通过后，仓库可用数量是否扣减需验证
- 项目字段显示异常（前端调用问题）
- 领用申请目前可能仍在页面上直接审批，未完全走工作流

---

### 2.5 移动端验收

**已实现：**
- 独立菜单"手机端专属"
- 页面：`/mobile/acceptance`
- 列出可验收的采购申请
- 点击进详情页（当前有 bug）

**已知问题：**
- 列表点击无响应
- 详情页显示"未关联项目"
- `Toast.loading is not a function` 报错

---

### 2.6 用户与角色

**已创建的测试账号：**

| 账号 | 角色 | 用途 |
|---|---|---|
| admin | 系统管理员 | 全部权限 |

## 四、当前最大的阻塞点

按优先级排序：

### P0（必须立刻修）

1. **普通用户无法提交申请**  
   导致除了 admin 外，其他人基本无法使用系统。

2. **审批人未正确进入审批流**  
   admin 代批后，实际审批人可能看不到任务。

3. **验收/领用流程状态与业务状态不同步**  
   保存草稿、重复验收、自动入库/扣库存等逻辑混乱。

### P1（本周内修）

4. 移动端验收页面无法使用。
5. 时间格式、图片加载、附件 404 等前端展示问题。
6. 驳回后重新提交的闭环。

### P2（后续优化）

7. 数据权限（项目负责人只能看自己项目数据）。
8. 项目预算父子校验。
9. 列表隐藏编码等 UI 调整。

## 六、一句话总结

> 主链路（采购申请 → 审批 → 验收 → 入库 → 领用）已经搭起来了，也能跑通一部分，但**权限和普通用户可用性、审批流稳定性、验收/领用状态同步**是当前最大的坑。先把这些修稳，再继续做 BOM、合同、报销。

---

## 七、下一步建议

如果明天要冲刺，建议按这个顺序：

1. **修权限**：让普通用户能提交采购/验收/领用申请。
2. **修流程**：确保项目负责人、团队上级、部门上级、仓库管理员能正确收到待办。
3. **修验收**：去重、入库、图片/附件显示。
4. **修领用**：审批通过后扣减库存。
5. **加资金管理**：采购通过时记流水。
