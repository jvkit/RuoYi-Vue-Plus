## 三、MinIO / 文件存储

### 服务器现状
- **Langfuse 自带 MinIO**：容器 `langfuse-minio-1`，端口映射 `9092:9000`。
- **OA 文件存储**：当前 OSS 记录中的 URL 形如 `http://127.0.0.1:9000/ruoyi/...`。
  - 这说明 OA 上传文件时连接的 MinIO 在 `127.0.0.1:9000`。
  - 但服务器上**没有独立运行的 ruoyi MinIO 容器**，只有 Langfuse 的 MinIO 在 `9092`。
  - 因此浏览器端访问 OA 上传的图片/PDF 时，内网 URL 无法解析，表现为仓库验收图片显示通用图标、发票 PDF 预览可能失败。

### 本地开发
- 本地开发时 `127.0.0.1:9000` 可达（本地启动了 MinIO），所以图片/PDF 正常。

### 待处理
- 方案 A：在服务器为 OA 单独部署 MinIO（端口 9000），并配置外网可访问的 endpoint。
- 方案 B：让 OA 复用 Langfuse 的 MinIO（端口 9092），修改 OSS 配置中的 endpoint。
- 方案 C：给 nginx 增加 MinIO 反向代理，将外部 9000 映射到内部 9092。
