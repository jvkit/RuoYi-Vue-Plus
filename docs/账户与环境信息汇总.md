## 三、MinIO / 文件存储

### 服务器（2026-09-03 已按方案 A 部署完成）
- **OA 独立 MinIO**：docker 容器 `minio`（`minio/minio:latest`，`--restart unless-stopped`）。
  - 数据 API：`http://172.16.16.110:9000`（UFW 已放行）；控制台：`http://172.16.16.110:9001`。
  - 凭据：`ruoyi` / `ruoyi123`；数据卷 `minio-data` → `/data`。
  - 桶 `ruoyi` 匿名策略 `download`（公开读，与本地一致）。
- **Langfuse 自带 MinIO**：容器 `langfuse-minio-1`，端口映射 `9092:9000`，**仅供 Langfuse 使用，勿混用**。
- **OSS 配置**（`sys_oss_config` minio 行）：endpoint `127.0.0.1:9000`（后端本机上传），domain_url `172.16.16.110:9000`（前端访问），URL 生成规则是 domain 优先。
- 存量 `sys_oss.url` 已批量替换为 `http://172.16.16.110:9000/...`（幂等脚本 `ruoyi-6x/script/sql/procurement_6x_v13_minio_domain.sql`）。
- **注意 Redis 缓存坑**：`sys_oss` 是 Redis hash（ossId → 含 url 的 JSON），直接改库后必须 `DEL sys_oss`（或重启 Redis），否则后端继续返回旧 URL。

### 本地开发
- 本地 MinIO 容器 `minio`，端口 `9000`（API）/ `9001`（控制台），凭据 `ruoyi` / `ruoyi123`，桶 `ruoyi` 同样公开读。
