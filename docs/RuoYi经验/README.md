本目录汇总在 RuoYi-Vue-Plus 6.x 二开过程中踩过的坑、验证过的机制与推荐做法。后续遇到同类问题优先来这里查，避免重复踩坑。

## 核心原则

1. **SQL 必须幂等**：所有数据库改动（菜单、角色、字典、表结构）写成 `ruoyi-6x/script/sql/` 下的脚本，保证可重复执行。
2. **本地改本地测**：代码与 SQL 都在本地修改验证，确认后再同步到服务器。
3. **改动最小化**：只改当前需求涉及的文件，不做 opportunistic 重构。
