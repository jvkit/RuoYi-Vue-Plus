# 部署与运行

## 1. 后端重启

代码改动后必须重新打包：

```bash
cd ruoyi-6x
mvn package -DskipTests -pl ruoyi-admin -am -q
```

启动时要用 `disown`，否则 Bash 会话退出可能把进程带掉：

```bash
nohup java -jar ruoyi-admin/target/ruoyi-admin.jar --server.port=8091 > /tmp/ruoyi-6x-admin.log 2>&1 & disown
```

> 不要用 `pkill -f 'ruoyi-admin.jar ...'`，因为命令行本身包含该字符串，pkill 可能把当前 shell 一起杀掉。

## 2. 前端热更新

`pnpm dev` 启动的 Vite 开发服务器通常会自动热更新，但新增文件或修改 `src/router/index.ts` 等入口文件时可能需要手动刷新页面。

## 3. 数据库脚本执行

```bash
docker exec -i mysql mysql -uroot -proot -D ry-vue-6x --default-character-set=utf8mb4 < xxx.sql
```

所有脚本必须 `SET NAMES utf8mb4;` 开头。

## 5. 常见非致命告警

- `UnknownHostException: net`：Spring Boot Admin 注册失败，可忽略。
- `SnailJob gRPC 连不上`：任务调度服务端未启动，可忽略。
- `SaTokenContext 上下文尚未初始化`：在虚拟线程里调用了需要 SaToken 上下文的方法，需改为查库或其他方式。
