# 工作流 Warm-Flow

## 1. 条件分支必须走网关节点

普通 `BETWEEN` 节点（`node_type=1`）的出边只取第一条 `PASS` 的 `flow_skip`，不判断条件。

条件分支必须放在**排他网关**（`node_type=3` SERIAL）上，格式：

```
lt@@amount|1000    # amount < 1000
gt@@amount|1000    # amount >= 1000
```

## 2. 角色审批

节点 `permission_flag` 写 `role:<角色id>`，例如 `role:1761300000000000009`。

引擎会自动把该角色下的所有用户作为候选人。任意一个用户审批通过即可。

> 不需要硬编码用户 ID。

## 3. 动态变量

可以在流程变量里传用户 ID，例如 `${applicantId}`、`${leaderId}`，在提交时从业务对象里取。

## 4. 审批跳转详情页

`formPath` 取 `flow_definition.form_path`。详情页必须：
- 存在于 `src/views/...`
- 在 `sys_menu` 里挂隐藏菜单
- 用户角色绑定该隐藏菜单
