# 前端路由与菜单

## 1. 菜单由后端驱动

前端 `src/router/index.ts` 只有少量静态路由（登录、404 等）。业务路由全部来自后端 `/system/menu/getRouters`。

`src/permission.ts` 登录后调用：

```ts
usePermissionStore().generateRoutes()
```

内部把后端返回的菜单树通过 `filterAsyncRouter` 映射为 `src/views/**/*.vue` 组件。

## 2. component 路径必须一一对应

后端菜单的 `component` 字段必须等于 `src/views/` 下的相对路径（不含 `.vue`）。

例如：
- 菜单 `component = procurement/request/index`
- 对应文件 `src/views/procurement/request/index.vue`

不一致会报 404 或组件加载失败。

## 3. 外部链接菜单

在菜单管理里把外链地址填到 `path` 字段，类型为目录，并勾选「是否外链=否」（走 InnerLink 内嵌）。

后端会生成：
- 父路由 path `/`，component `Layout`
- 子路由 path 为把 `http://` 和 `.` 替换为 `/` 后的路径，component `InnerLink`
- 子路由 `meta.link` 保留原始 URL

示例：`http://172.16.16.110:3305` 生成子路由 `/172/16/16/110/3305`。

## 4. 首页按钮动态跳转外链

不要在前端硬编码外链 IP。应读取 `permissionStore.sidebarRouters`，按 `meta.title` 或 `meta.link` 找到 PRIME AI 路由，再 `router.push`。

示例见 `src/views/index.vue` 的 `findPrimeAiPath` 实现。
