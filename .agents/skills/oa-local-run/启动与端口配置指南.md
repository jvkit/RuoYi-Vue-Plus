## 三、启动前依赖

### 3.1 Docker 基础服务

必须先把 MySQL 和 Redis 容器启动：

```bash
docker start mysql redis
```

验证：

```bash
docker ps --filter "name=mysql|redis" --format "table {{.Names}}\t{{.Status}}"
```

输出示例：

```
NAMES    STATUS
mysql    Up x minutes
redis    Up x minutes
```

### 3.2 后端 jar 必须存在

6x 后端 jar 路径：

```
ruoyi-6x/ruoyi-admin/target/ruoyi-admin.jar
```

Snail-AI 服务 jar 路径：

```
ruoyi-6x/ruoyi-extend/ruoyi-snailai-server/target/ruoyi-snailai-server.jar
```

如果 jar 不存在，先打包（跳过测试）：

```bash
cd /home/jvkit/workspace/oa/ruoyi-6x
mvn package -DskipTests
```

产物位置：

- `ruoyi-6x/ruoyi-admin/target/ruoyi-admin.jar`
- `ruoyi-6x/ruoyi-extend/ruoyi-snailai-server/target/ruoyi-snailai-server.jar`

## 四、6x 启动命令（推荐顺序）

### 4.1 启动后端

```bash
cd /home/jvkit/workspace/oa/ruoyi-6x/ruoyi-admin
nohup java -jar target/ruoyi-admin.jar --server.port=8091 > /tmp/ruoyi-6x-admin.log 2>&1 &
```

查看启动日志：

```bash
tail -f /tmp/ruoyi-6x-admin.log
```

启动成功标志：

```
Started DromaraApplication in xx.xxx seconds
RuoYi-Vue-Plus启动成功
```

验证端口：

```bash
ss -tlnp | grep 8091
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8091/swagger-ui/index.html
# 应返回 200
```

### 4.2 启动 Snail-AI 服务

```bash
cd /home/jvkit/workspace/oa/ruoyi-extend/ruoyi-snailai-server
nohup java -jar target/ruoyi-snailai-server.jar --server.port=8900 > /tmp/ruoyi-snailai-server.log 2>&1 &
```

> 该服务默认 web 端口 `8900`，上下文路径 `/snail-ai`，gRPC 端口 `18888`。
> 启动后 6x 后端通过 gRPC `127.0.0.1:18888` 与其通信。

验证：

```bash
ss -tlnp | grep -E "8900|18888"
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8900/snail-ai/
# 应返回 200 或 401（有认证页）
```

### 4.3 启动前端

```bash
cd /home/jvkit/workspace/oa/plus-ui-6x
pnpm dev
```

> 不需要 `nohup`，开发服务器保持前台即可；如要后台：
>
> ```bash
> nohup pnpm dev > /tmp/plus-ui-6x-dev.log 2>&1 &
> ```

启动成功后控制台输出：

```
Local:   http://localhost:8082/
Network: http://10.x.x.x:8082/
```

### 4.4 访问

浏览器打开：`http://localhost:8082`

默认账号：`admin / admin123`

## 五、一键启动脚本（6x 全栈）

```bash
#!/bin/bash
cd /home/jvkit/workspace/oa

# 1. 启动基础设施
docker start mysql redis

# 2. 启动 6x 后端
nohup java -jar ruoyi-6x/ruoyi-admin/target/ruoyi-admin.jar --server.port=8091 > /tmp/ruoyi-6x-admin.log 2>&1 &

# 4. 启动前端（前台，保留终端）
cd plus-ui-6x && pnpm dev
```

保存为 `scripts/start-6x.sh`，需要时执行即可。

## 六、停止命令

### 6.1 停止后端

```bash
# 6x 主后端
pkill -f "ruoyi-6x/ruoyi-admin/target/ruoyi-admin.jar"

# Snail-AI 服务
pkill -f "ruoyi-snailai-server.jar"
```

或按 PID 杀：

```bash
ps aux | grep ruoyi-admin.jar
ps aux | grep ruoyi-snailai-server.jar
kill <PID>
```

### 6.2 停止前端

前台 `pnpm dev` 直接 `Ctrl + C`；如为后台进程：

```bash
pkill -f "pnpm dev"
# 或按 vite 进程
pkill -f "vite serve"
```

### 6.3 停止数据库

```bash
docker stop mysql redis
```

## 七、换端口要改哪些文件

### 7.1 改 6x 主后端端口

两种方法，推荐第一种：

**方法 A：启动参数覆盖（不改源码，推荐）**

```bash
java -jar target/ruoyi-admin.jar --server.port=8099
```

**方法 B：改配置文件**

文件：`ruoyi-6x/ruoyi-admin/src/main/resources/application.yml`

```yaml
server:
  port: 8091   # 改成你要的端口
```

改完需重新打包：

```bash
cd /home/jvkit/workspace/oa/ruoyi-6x
mvn package -DskipTests
```

### 7.2 改 Snail-AI 服务端口

**方法 A：启动参数覆盖**

```bash
java -jar target/ruoyi-snailai-server.jar --server.port=8901
```

> gRPC 端口 `18888` 在 `application.yml` 的 `snail-ai.server.grpc-port` 中配置，如需修改要改配置文件后重新打包。

**方法 B：改配置文件**

文件：`ruoyi-6x/ruoyi-extend/ruoyi-snailai-server/src/main/resources/application.yml`

```yaml
server:
  port: 8900
  servlet:
    context-path: /snail-ai

snail-ai:
  server:
    grpc-port: 18888
```

改完重新打包。

### 7.3 改前端 dev 端口

文件：`plus-ui-6x/.env.development`

```env
VITE_APP_PORT = 8082   # 改成你要的端口
```

改完重启 `pnpm dev` 生效。

### 7.4 改前端代理的后端地址

6x 前端默认把 `/dev-api` 代理到 `http://127.0.0.1:8091`，如果后端换了端口，前端代理也要改。

文件：`plus-ui-6x/vite/vite.config.ts`（或 `.env.development` 中相关代理配置）

查找 `proxy` 配置段，把 target 改为对应后端端口。

### 7.5 改数据库/Redis 连接

文件：`ruoyi-6x/ruoyi-admin/src/main/resources/application-dev.yml`

```yaml
spring:
  datasource:
    dynamic:
      datasource:
        master:
          url: jdbc:mysql://localhost:3306/ry-vue-6x?...
          username: root
          password: root
  redis:
    host: localhost
    port: 6379
    password: ruoyi123
```

改完重新打包。

> **注意**：Snail-AI 服务自己有独立数据源配置，位于 `ruoyi-6x/ruoyi-extend/ruoyi-snailai-server/src/main/resources/application-dev.yml`，默认连 `ry-vue` 库。

## 十、常见问题

### 10.1 端口被占用

```bash
# 查看占用端口的进程
ss -tlnp | grep 8091

# 杀掉
kill <PID>
```

### 10.2 MySQL 没启动

```bash
docker ps -a | grep mysql
docker start mysql
```

### 10.3 后端报 `UnknownHostException: net`

这是 Spring Boot Admin 客户端注册失败，本机主机名 `net` 解析失败。**不影响登录和常规接口**，可忽略。如不需要监控，不必启动 `ruoyi-extend/ruoyi-monitor-admin`。

### 10.4 SnailJob gRPC 连不上

`ruoyi-snailjob-server` 未启动导致，**不影响登录和常规接口**，可忽略。需要定时任务时再启动。

### 10.5 前端页面空白/404

- 确认前端 dev 代理指向正确后端端口
- 确认后端 `sys_menu` 表有对应菜单
- 确认 `src/views/` 下存在对应 `.vue` 文件

### 10.6 Snail-AI 服务启动失败

**表不存在**：若日志提示 `Table 'ry-vue.sai_xxx' doesn't exist`，说明 `ry-vue` 库还没初始化 Snail-AI 表。执行：

```bash
cd /home/jvkit/workspace/oa
echo "SET NAMES utf8mb4;" | cat - ruoyi-6x/script/sql/ry_ai.sql > /tmp/ry_ai_utf8.sql
docker exec -i mysql mysql -uroot -proot -D ry-vue --default-character-set=utf8mb4 < /tmp/ry_ai_utf8.sql
```

**Elasticsearch 连不上**：若日志提示 ES 连接失败，说明当前环境未部署 ES。AI 服务 RAG/OCR 能力依赖 ES，**一阶段传统采购不依赖 Snail-AI**，可先不启动；如需完整 AI 功能，需先部署 Elasticsearch（或把 `rag` 配置关闭）。

**Spring Boot Admin 连不上 9090**：非致命错误，不影响 Snail-AI 自身服务。
